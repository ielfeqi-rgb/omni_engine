🌐 كيفية الاتصال بمحرك Omni من التطبيقات الخارجية (OpenAI Compatible)

                    

                        المحرك متوافق 100% مع معايير OpenAI API. يمكنك توجيه أي مكتبة أو تطبيق إلى:
                    

                    
http://127.0.0.1:8090/v1  (أو رابط الـ IP الخاص بجهازك)

                    
                    
مثال لاستخدام cURL:

                    
curl http://127.0.0.1:8090/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer omni_sk_YOUR_KEY_HERE" \
  -d '{
    "messages": [{"role": "user", "content": "Hello AI!"}],
    "stream": false
  }'


                    
مثال باستخدام Python OpenAI Library:

                    
from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:8090/v1",
    api_key="omni_sk_YOUR_KEY_HERE"
)

response = client.chat.completions.create(
    model="omni-model",
    messages=[{"role": "user", "content": "مرحبا بك!"}]
)

print(response.choices[0].message.content)
